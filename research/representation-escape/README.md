**Representation Escape: Separating Structure in Reality from Structure Inherited from the Path, the Hardware, and the Observer**

## Final paper

- `Representation_Escape_Narrative_2026-10-02_v31.tex` — final LaTeX manuscript source.
- `Representation_Escape_Narrative_2026-10-02_v31.pdf` — rebuilt automatically by GitHub Actions.
- `make_figures.py` — regenerates the five figures used by the paper from checked-in data and the paper's stated geometric constructions.
- `figures/` — generated by the build.
- `repro/` — controlled-search and evidence-ceiling data plus reproducibility code.

## Build locally

```bash
python3 -m pip install numpy matplotlib
python3 make_figures.py
pdflatex -interaction=nonstopmode -halt-on-error Representation_Escape_Narrative_2026-10-02_v31.tex
pdflatex -interaction=nonstopmode -halt-on-error Representation_Escape_Narrative_2026-10-02_v31.tex
```

GitHub Actions performs the same build and commits both the PDF and a source-bundle ZIP.

## Scientific scope

The Fourth Side is a constructive mathematical visualization of a four-coordinate representation. It is not presented as evidence that physical spacetime contains a fourth macroscopic spatial dimension.
