# Build manifest

This directory is the publication snapshot for **Representation Escape**.

The checked-in source tree contains:

- final LaTeX manuscript source;
- reproducibility data for the evidence-ceiling and consequence-targeted-search experiments;
- the executable consequence-targeted-search benchmark;
- a figure-generation script and generated figures;
- the Fourth Side renderer, film assembly source, geometry/research scripts, generated scene values, timeline, and verification outputs;
- a GitHub Actions build that regenerates the PDF and source-bundle ZIP from the checked-in source.

The generated PDF and source bundle are committed by the build workflow after a successful clean build.
