# Independent Verification Checklist

The proposed compression should be regarded as broken if a valid audit establishes any of the following.

1. **Hidden same-grade cycle.** A legal return cycle exists with total filtration degree zero or below.
2. **Illegal typed use of Proposition 7.6.** A covariance identity is applied to a generic wave rather than a wave in the signed-stress operator image.
3. **Illegal stress target.** Stress preparation fails to produce an admissible compact target for the signed-stress inverse.
4. **Admissibility failure.** The linear or quadratic retained error leaves the exact compatibility subspace.
5. **Worse quadratic channel.** An overlooked quadratic interaction destroys the positive nonlinear difference gain.
6. **Higher algebraic pressure degree.** Exact pressure reconstruction introduces a genuine cubic-or-higher correction term around the fixed initialized state.
7. **Compiler/execution mismatch.** A finite compiler output cannot be expanded into the finite legal primitive operations permitted by the source architecture.
8. **Flat-tail leakage.** A permitted finite operation converts a flat remainder into a fixed finite-order residual.
9. **Target-dependent domain collapse.** The common physical domain must shrink with target accuracy in a way not covered by the source common-domain proof.
10. **Target-dependent exponent loss.** Physical derivative exponent losses grow with target accuracy rather than depending only on fixed derivative order.
11. **Hidden genealogy dependence.** A downstream result uses how stage `j` was produced rather than only the interface properties claimed here.
12. **Non-nested accuracy family.** For some `B > A`, the difference `X_B - X_A` contains terms below the claimed shell order `A`.
13. **Wrong fixed background.** A coefficient placed in the fixed linear operator must actually depend on later corrections at the same filtration grade.
14. **Growing primitive family.** Higher target accuracy requires genuinely new inverse operators or compatibility conditions.

The strongest positive check is a complete arrow-by-arrow audit of every return exponent entering or leaving `W`, `Mbar`, `Mcirc`, and `S`.
