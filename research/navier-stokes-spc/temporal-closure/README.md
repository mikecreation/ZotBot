This directory is the public proof/reproducibility package for the temporal-reconstruction result that follows the earlier Structural Path Compression (SPC) manuscript.

## One-sentence result

The OpenAI formalization already proves a one-state temporal reconstruction estimate. This package adds a **two-state congruence theorem** and its **genuine all-order corollary**: residual-source differences that are invisible at every finite `MeanClass` order remain invisible after temporal reconstruction, under shared reconstruction geometry and the stated admissibility hypotheses.

## What is new, precisely

The baseline OpenAI tree contains:

- `NavierStokes.VariableGaugeMean.temporalIncrementState_classes`

This package adds:

- `NavierStokes.VariableGaugeMean.temporalIncrementState_difference_classes`
- `NavierStokes.VariableGaugeMean.temporalIncrementState_flat_classes`

The finite-grade exponent transfer is inherited from the existing source theorem. The new formal increment is the **difference/congruence theorem** and its **all-order closure statement**, not a new analytic gain estimate.

## Claim boundary

This package certifies the temporal-reconstruction congruence only. It does **not** by itself certify:

- debt closure;
- rank closure;
- full-cycle preservation of the all-order class;
- a complete quotient evolution `C / I_infinity`;
- the full stage-free SPC theorem;
- a new Navier-Stokes blowup theorem;
- absolute worldwide priority for the underlying functional-analytic fact.

The next live formal target is the debt bridge.

## Relation to the first SPC paper

The first paper asks whether a successful staged proof trajectory contains representation-induced repetition that can be compiled into a smaller generator. This second paper tests the idea in the stricter language required by quotient mathematics:

> **A deletion is safe only when future operators cannot make the deleted distinction visible again.**

Temporal reconstruction is now one machine-certified instance of that principle.
