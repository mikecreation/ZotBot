higher-order function
Any
function
that maps a function to anything or maps anything to a function is a
higher-order function
. In programming language terms, a higher-order function is any function that takes one or more functions as
arguments
and/or returns a function.
For example, a
predicate
which makes some statement about a function would be a higher-order function.
