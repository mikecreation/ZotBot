Ackermann's function
Ackermann's function
(algorithm)
Definition:
A function of two parameters whose value grows very fast.
Formal Definition:
A(0, j)=j+1			for j ≥ 0
A(i, 0)=A(i-1, 1)			for i > 0
A(i, j)=A(i-1, A(i, j-1))		for i, j > 0
See also
inverse Ackermann function
.
Note:
Many people have defined other similar functions which are not simply a restating of this one.
In 1928,
Wilhelm Ackermann
observed that A(x,y,z), the z-fold iterated exponentiation of x with y, is a recursive function that is not primitive recursive. A(x,y,z) was simplified to a function of 2 variables by  Rózsa Péter in 1935.  Raphael M. Robinson simplified the initial condition in 1948.
