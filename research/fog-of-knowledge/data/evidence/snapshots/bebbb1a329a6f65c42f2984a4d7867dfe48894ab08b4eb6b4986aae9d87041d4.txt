dynamic array
dynamic array
(data structure)
Definition:
An
array
whose size may change over time.  Items are not only added or removed, but memory used changes, too.
Note:
For instance,
REDIM
in Visual Basic or
malloc()
in C.  In some languages, such as Perl, all arrays are dynamic.
