height
height
(definition)
Definition:
The maximum distance of any
node
from the
root
. If a tree has only one node (the root), the height is zero.   The height of an empty tree is not defined.
See also
depth
,
level
.
Note:
An equivalent definition is: the height is the maximum
depth
of any node.
The height of the figure at the definition of
tree
is two.
The height of a tree is also known as the
order
.
