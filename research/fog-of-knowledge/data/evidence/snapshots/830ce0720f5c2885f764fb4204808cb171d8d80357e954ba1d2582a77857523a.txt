recognizer
(definition)
Definition:
A
finite state machine
with one or more
states
designated as
accepting states
.  An input string is
accepted
if there is a
path
from the
start state
to an accepting state.
See also
deterministic finite state machine
,
nondeterministic finite state machine
.
