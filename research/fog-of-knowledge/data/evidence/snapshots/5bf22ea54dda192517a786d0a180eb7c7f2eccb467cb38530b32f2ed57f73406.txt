Kolmogorov complexity
Kolmogorov complexity
(definition)
Definition:
The minimum number of bits into which a
string
can be compressed without losing information.  This is defined with respect to a fixed, but universal decompression scheme, given by a
universal Turing machine
.
See also
incompressible string
.
