array search
(classic problem)
Definition:
Find an element in an
array
.  Various algorithms exist which require more or less structure in the array elements or implementation.
See also
linear search
,
binary search
,
interpolation search
,
string matching
.
Note:
An
external index
, such as a
hash table
or
inverted index
may help make the search quicker and speed overall processing if the array is not changed often.
