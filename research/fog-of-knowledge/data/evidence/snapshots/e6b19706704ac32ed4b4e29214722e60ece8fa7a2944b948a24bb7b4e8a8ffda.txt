Shift-Or
Shift-Or
(algorithm)
Definition:
A
string matching
algorithm which keeps an
array
of bits, R, showing if
prefixes
of the
pattern
don't match at the current place.  Before searching, mismatch arrays are computed for each character in the
alphabet
and saved in an array, S.  For the next position, with the character c, R = shift(R)
or
S[c].  If the last bit of R is 0, the pattern matches.
