maximal independent set
maximal independent set
(classic problem)
Definition:
A set of
vertices
in a
graph
such that for any pair of vertices, there is no
edge
between them and such that no more vertices can be added and it still be an
independent set
.
Note:
It is
NP-complete
to decide if there is maximal independent set of size k in a graph.
