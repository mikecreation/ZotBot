Karp-Rabin
Karp-Rabin
(algorithm)
Definition:
A
string matching
algorithm that compares string's
hash
values, rather than the strings themselves.  For efficiency, the hash value of the next position in the text is easily computed from the hash value of the current position.
Also known as
Rabin-Karp.
Author:
PEB
Implementation
Christian Charras' and Thierry Lecroq's
Exact String Matching Algorithms (C)
,
description and animation (C)
,
(C and Pascal)
.
