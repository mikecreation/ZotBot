Shannon-Fano coding
Shannon-Fano coding
(algorithm)
Definition:
A variable-length coding based on the frequency of occurrence of each character.  Divide the characters into two
sets
with the frequency of each set as close to half as possible, and assign the sets either 0 or 1 coding.  Repeatedly divide the sets until each character has a unique coding.
See also
arithmetic coding
,
Huffman coding
,
Zipf's law
.
Note:
Shannon-Fano is a minimal prefix code. Huffman is optimal for character coding (one character-one code word) and simple to program.  Arithmetic coding is better still, since it can allocate fractional bits, but is more complicated and has patents.
