path
path
(definition)
Definition:
A list of
vertices
of a
graph
where each vertex has an
edge
between it and the next vertex.
Specialization
(... is a kind of me.)
simple path
,
shortest path
,
cycle
,
Hamiltonian cycle
,
Euler cycle
,
alternating path
.
See also
all pairs shortest path
,
all simple paths
.
Note:
A path is usually assumed to be a
simple path
, unless otherwise defined.
In a
directed graph
, each vertex has an edge from it to the next vertex.
