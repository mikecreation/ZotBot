lucky sort
lucky sort
(algorithm)
Definition:
The best possible
sort
algorithm: it is so lucky that the input is already sorted, and it need do nothing!
See also
bogosort
,
bozo sort
,
stooge sort
.
Note:
Defined more for humorous, rather than serious, purposes. Time complexity is Θ(0) (zero): it takes no time.
