Smith algorithm
Smith algorithm
(algorithm)
Definition:
A
string matching
algorithm which computes the shift value for both the rightmost character of the
window
and the character preceding it, then uses the maximum of the two values.
Author:
BB
Implementation
visualization and code (C)
More information
P. D. Smith
,
Experiments with a very fast substring search algorithm
, Software Practice & Experience, 21(10):1065-1074, 1991.
