state machine
(definition)
Definition:
A
model of computation
consisting of a (possibly infinite) set of
states
, a set of
start states
, an input
alphabet
, and a
transition function
which maps input symbols and current states to a
next state
.  Usually understood to be a
finite state machine
.
Generalization
(I am a kind of ...)
model of computation
.
Specialization
(... is a kind of me.)
finite state machine
.
