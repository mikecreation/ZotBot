primitive recursive
primitive recursive
(definition)
Definition:
A
total function
that can be written using only nested conditional (if-then-else) statements and fixed iteration (for) loops.
See also
computable
.
Note:
Ackermann's function
is
computable
, but is not primitive recursive.  Primitive recursive functions always terminate.  More powerful languages have some functions that cannot be proved to either terminate or run forever.
