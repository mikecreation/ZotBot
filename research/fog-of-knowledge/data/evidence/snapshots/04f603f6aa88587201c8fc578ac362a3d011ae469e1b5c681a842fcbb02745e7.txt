multilayer grid file
multilayer grid file
(data structure)
Definition:
A
spatial access method
which is two or more simultaneous
grid files
.  Objects reside in the first grid file where it doesn't have to be split across hyperplanes.
See also
twin grid file
.
Note:
After
[GG98]
.
