parallel random-access machine
(definition)
Definition:
A
shared memory
model of computation
, where typically the processors all execute the same instruction synchronously, and access to any memory location occurs in unit time.
Also known as
PRAM.
Aggregate child
(... is a part of or used in me.)
shared memory
.

work-depth model
,
multiprocessor model
.
