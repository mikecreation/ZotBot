# Experiments and Falsifiers

## Experiment 1: Three-arm target assignment

Randomize participants to three vocabularies while holding cases constant.

### Arm U: Umbrella
Uses inherited terms such as “lost consciousness” and “regained consciousness.”

### Arm E: Experience-centered decomposition
Reserves consciousness for phenomenal experience and names response, connectedness, memory, and organism persistence separately.

### Arm Γ: SCTC decomposition
Reserves consciousness for system-level biological continuity and names phenomenal experience separately as `E`.

### Shared forced outputs
Every arm must answer:
1. same individual / ended / indeterminate;
2. experience present / absent / unknown;
3. responsiveness present / absent / unknown;
4. connectedness present / absent / unknown.

“Unknown” must never be scored as a state flip. The missingness mechanism is preregistered.

### Primary SCTC criterion

`V_Γ < V_E` AND `Err_E(Γ) - Err_E(E) <= ε_E`.

The Γ vocabulary must reduce unsupported reclassification without sacrificing accuracy on experience itself.

## Experiment 2: Closed-inventory system-level discontinuity test

Freeze the candidate faculty set before data inspection:

`F* = (W,E,K,R,M,P,Q,S,I)`

Search for a variable `Z` that changes with biological continuity preserved and still adds independent predictive or interventional information after conditioning on the frozen inventory and measurement availability. Require replication across at least two preregistered paradigms.

A surviving `Z` that is necessary for the classifications science intends by consciousness falsifies the sufficiency of `C := L_B`.

## Experiment 3: Faculty Exclusion Atlas

Create a cross-condition matrix for wakefulness, anesthesia, dreaming, amnesia, sensory loss, cognitive motor dissociation, organ replacement, temporary arrest/resuscitation, and other cases. Record biological continuity and each faculty independently.

This atlas does not prove SCTC’s primitive definition. Its purpose is to prevent one coordinate from being inferred from another without evidence.

## Failure conditions

SCTC loses if a nearest rival performs better under the preregistered comparison, if an independent system-level `Z` survives, if biological individuality cannot be operationalized sufficiently for the intended domain, or if the biological-substrate restriction fails.
